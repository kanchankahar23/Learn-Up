# 📚 Learn-Up

**Learn-Up** is a front-end web project that demonstrates core concepts of user authentication and a basic payment interface.  
It is built using **HTML, CSS, and JavaScript**, with a focus on clean UI and responsive design.

---

## 🚀 Features

- 🏠 **Landing Page** – Main entry point with navigation  
- 🔑 **User Authentication** – Sign-In and Sign-Up forms  
- 💳 **Payment Page** – Simple payment interface  
- 🎨 **Custom Styling** – Built with pure CSS  
- ⚡ **Interactive Behavior** – Handled with Vanilla JavaScript  

---

## 📂 Project Structure

Learn-Up/
│── index.html # Home / Landing Page
│── sign-in.html # User Login
│── sign-up.html # User Registration
│── payment.html # Payment Page
│── style.css # Global Stylesheet
│── script.js # JavaScript Interactivity

---

## 🛠️ Tech Stack

- **HTML5** – Page structure  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Client-side interactivity
